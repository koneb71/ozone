# __OZONE_APP_NAME__

A full-stack web app: TanStack Start (React 19, file-based routes, server functions), Tailwind CSS 4 with shadcn-style components, Postgres through Drizzle ORM, and Better Auth for accounts. It runs in Docker Compose.

## Commands

Node and the dependencies live inside the app's container, not on this machine. Run every project command through `./dev`:

| To                                  | Run                             |
| ----------------------------------- | ------------------------------- |
| Check types                         | `./dev npm run typecheck`       |
| Check lint and formatting           | `./dev npm run lint`            |
| Fix lint and formatting             | `./dev npm run format`          |
| Run the tests                       | `./dev npm run test`            |
| Build for production                | `./dev npm run build`           |
| Add a dependency                    | `./dev npm install <package>`   |
| Write a migration after a schema change | `./dev npm run db:generate` |
| Apply migrations                    | `./dev npm run db:migrate`      |

The dev server is already running with hot reload. Saved edits appear without a restart.

## Where things go

- `src/routes/` holds pages and API routes. A file is a route: `src/routes/habits.tsx` is `/habits`, `src/routes/api/health.ts` is `/api/health`. `src/routeTree.gen.ts` is generated: never edit it.
- `src/components/ui/` holds the base components (button, card, input, label). Add new ones in the same style. This app's own components go in `src/components/`.
- `src/db/schema.ts` holds this app's tables. `src/db/auth-schema.ts` is generated by Better Auth: do not edit it.
- `drizzle/` holds generated SQL migrations. Never edit or delete one that already exists.
- `src/lib/auth.ts` is the server's auth configuration. `src/lib/auth-client.ts` exports `authClient` for the browser.
- `src/styles/app.css` holds the design tokens.

## How to write it

- The installed TanStack packages ship guides that match their version. Read the one for what you are about to write, for example `./dev cat node_modules/@tanstack/start-client-core/skills/start-core/server-functions/SKILL.md`. List them all with `./dev find node_modules/@tanstack -name SKILL.md`.
- Loaders run in the browser too. Read and write the database only inside `createServerFn` handlers or server route handlers. `src/db` is server-only, and importing it into browser code fails the build.
- A server function is a public endpoint. Check the session inside every handler that touches private data, and validate its input with zod through `.validator(...)`.
- After a write, `await router.invalidate()` so the loader reads what was saved. Do not patch local state instead.
- Style with Tailwind utilities and the tokens: `bg-background`, `text-muted-foreground`, `border-border`, `bg-primary`. No colour literals in components. Light and dark must both look right.
- Every page works at 360 px wide and on a desktop. Controls are reachable by keyboard and have accessible names.
- Empty, loading and error states are part of the feature.
- Cover logic that can break with vitest tests next to the code (`*.test.ts`).

## Done means

`./dev npm run typecheck`, `./dev npm run lint` and `./dev npm run test` pass, and the feature works in the running app.
